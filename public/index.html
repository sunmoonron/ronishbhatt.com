how this page works⌁ event

This HTML is twenty-two lines plus one small script, and until you click something no library at all; everything else on the page is a Nostr event signed by this site's key and rendered in place. The page is pre-rendered from my relay at deploy, then your browser asks the relay again and rebuilds itself only if something changed, so edits appear live in every open tab. The blocks travel veiled (NIP-44 under a key that lives in this page, with hashed identifiers), so relays and Nostr clients see noise while anyone holding the page can read them; the chat is NIP-17 (NIP-59 gift wraps, NIP-44 encryption, NIP-13 proof of work), and the icon is the first sixteen hex digits of the signing key, one shade of green per digit.
