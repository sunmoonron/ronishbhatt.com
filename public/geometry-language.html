Why It Is Different

not grammar
Example: the word order is a non-commutative walk. "tone" and "note" use the same letters but arrive with different endpoint, area, and accumulated turn. The alphabet remains readable, while the sidecar carries geometry.

Encoding rule

state = (x, y, theta, mass) letter c -> T_c(state) word/sentence -> T_n ... T_2 T_1(state) signature -> hash(endpoint, area, turn, spectrum)

Letters are not tokens to parse. They are local transforms. Vowels inject curvature, consonants translate, punctuation reflects or rotates the frame, and spaces raise the next strand without deleting the old one.

Actual uses

  • Fast prefilter for search: reject distant text before paying for embeddings.
  • Prompt linting: high fold density marks conflicting instruction geometry.
  • Human-readable checksums: preserve the exact text and attach a visual signature.
  • Education: make cadence, repetition, and revision visible without grammar labels.
  • Model analysis: compare a model embedding path against a deterministic alphabet path.

Research boundary

Recent work maps language-model geometry in learned spaces: token topology, shared embedding manifolds, concept polytopes, hyperbolic token structure, representation phases, and reasoning flows. This page moves the geometric layer below the model, down to the alphabet itself.
