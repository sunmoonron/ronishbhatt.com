## Vision

Transform ephemeral social activity into **verifiable, timechain-anchored insights** that users own, can prove, and can share. By correlating Nostr activity with Bitcoin block heights, we create a unique value proposition: **provable social history** that no centralized platform can offer.

---

## The Core Insight

Nostr events have timestamps. Bitcoin blocks have timestamps AND proof-of-work. 
By anchoring social metrics to block heights, we get:
1. **Verifiable time** — "I was this active during block 800,000-810,000"
2. **Universal reference frame** — Block heights are the same for everyone on Earth
3. **Natural epochs** — Halvings, difficulty adjustments, and round blocks become social milestones
4. **Proof of presence** — Activity during specific blocks proves you were there

## Architecture

### Layer 1: Data Sources

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐

         │                       │                       │

                                 │
                         ┌───────▼───────┐
                         │ Event Indexer │
                         │  (Correlator) │
                         └───────┬───────┘
```

**Nostr Relays**: Social events (kind 0, 1, 3, 7, 9735 zaps)
**Mempool.space API**: Block heights, timestamps, difficulty, fee rates, notable txs
**Bitcoin Node**: Optional local verification for power users

### Layer 2: The Correlation Engine

Every Nostr event gets tagged with:
- `block_height`: Which Bitcoin block was most recent when this was posted
- `block_distance`: How many seconds after that block
- `difficulty_epoch`: Which difficulty adjustment period
- `halving_era`: Which halving cycle (currently era 4)

This transforms "posted at 1701648000" into "posted 847 seconds into block 820,142 (4th halving era, diff epoch 423)".

### Layer 3: Analytics & Insights

**Personal Metrics**
- Activity per 1000 blocks (normalized engagement rate)
- "Block streaks" — consecutive blocks with activity
- Halving-to-halving growth comparison
- Response time in blocks (not seconds — immune to timezone confusion)

**Social Metrics**
- Peer comparison: "You posted 3x more than the median during this difficulty epoch"
- Network-wide activity correlation with fee rates (do people post more during high-fee periods?)
- Zap velocity: sats/block flowing through your network

**Discovery Metrics**
- Who else was active during the same blocks as you?
- Find your "block twins" — users with similar activity patterns
- Historical moments: "Show me everyone who posted during the first Ordinals inscription block"

### Mempool.space API Integration

```javascript
class MempoolClient {
  constructor(baseUrl = 'https://mempool.space/api') {
    this.baseUrl = baseUrl;
    this.blockCache = new Map();
  }

  // Core endpoints we need
  async getBlockHeight() {
    return fetch(`${this.baseUrl}/blocks/tip/height`).then(r => r.json());
  }

  async getBlockAtTimestamp(timestamp) {
    // Returns the block that was mined closest to this time
    return fetch(`${this.baseUrl}/v1/mining/blocks/timestamp/${timestamp}`)
      .then(r => r.json());
  }

  async getBlocks(startHeight, count = 10) {
    // Batch fetch blocks for caching
    return fetch(`${this.baseUrl}/v1/blocks/${startHeight}`)
      .then(r => r.json());
  }

  async getDifficultyAdjustments() {
    return fetch(`${this.baseUrl}/v1/mining/difficulty-adjustments`)
      .then(r => r.json());
  }

  async getMempoolStats() {
    // Real-time mempool for "network health" indicator
    return fetch(`${this.baseUrl}/mempool`)
      .then(r => r.json());
  }

  async getHistoricalFees(blockHeight) {
    const hash = await this.getBlockHash(blockHeight);
    const block = await fetch(`${this.baseUrl}/block/${hash}`).then(r => r.json());
    return {
      medianFee: block.extras?.medianFee,
      avgFee: block.extras?.avgFee,
      totalFees: block.extras?.totalFees
    };
  }
}
```

### Block-Time Correlation

```javascript
class TimeAnchor {
  constructor(mempoolClient) {
    this.client = mempoolClient;
    this.blockIndex = []; // Sorted array of {height, timestamp}
  }

  async buildIndex(startTime, endTime) {
    // Build a local index of blocks for fast lookups
    // Mempool.space returns ~15 blocks per request
    const blocks = [];
    let currentHeight = await this.client.getBlockHeight();
    
    while (blocks.length === 0 || blocks[blocks.length - 1].timestamp > startTime) {
      const batch = await this.client.getBlocks(currentHeight);
      blocks.push(...batch);
      currentHeight -= batch.length;
    }
    
    this.blockIndex = blocks
      .filter(b => b.timestamp >= startTime && b.timestamp <= endTime)
      .sort((a, b) => a.timestamp - b.timestamp);
  }

  findBlockForTimestamp(timestamp) {
    // Binary search for nearest block
    let low = 0, high = this.blockIndex.length - 1;
    
    while (low < high) {
      const mid = Math.floor((low + high) / 2);
      if (this.blockIndex[mid].timestamp < timestamp) {
        low = mid + 1;
      } else {
        high = mid;
      }
    }
    
    // Return block that was mined just before this timestamp
    const idx = this.blockIndex[low].timestamp > timestamp ? low - 1 : low;
    return this.blockIndex[Math.max(0, idx)];
  }

  anchorEvent(event) {
    const block = this.findBlockForTimestamp(event.created_at);
    return {
      ...event,
      anchor: {
        block_height: block.height,
        block_hash: block.id,
        block_timestamp: block.timestamp,
        offset_seconds: event.created_at - block.timestamp,
        difficulty_epoch: Math.floor(block.height / 2016),
        halving_era: Math.floor(block.height / 210000)
      }
    };
  }
}
```
